A few useful details

Good questions.
Clear answers.

The Rack is being developed as a project concept. These notes explain the intended approach.

Does The Rack use NFC or indicator LEDs?+

No. The current project plan focuses on weight measurement, digital inventory, stock thresholds, refill alerts, and shopping-list management. NFC and LED features have been removed.

How will the spice quantity be estimated?+

A load cell and HX711 amplifier measure the load. The software will use calibration and the bottle's tare information to estimate spice quantity in grams.

Will the app show live updates?+

The intended architecture is ESP32 → Wi-Fi → Firebase → Android app. Real-time updates depend on completing and testing that hardware and cloud integration.
