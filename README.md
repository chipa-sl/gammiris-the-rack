# GamMiris The Rack website

Open index.html in a browser. Keep all folders together.

Pages: Home, The Rack, Dashboard, 3D Demo, Our Story.
Includes the Android APK, PDF user manual, app interface previews, and embedded textured 3D rack model.

The 3D viewer needs internet access to load Three.js and a browser with WebGL support. The model data is included locally.
